# Relatórios GPBR - VALE

App de celular para preencher os relatórios de inspeção, manutenção preventiva (MTM) e corretiva, com fotos tiradas no próprio app e relatório em PDF.

**Abrir o app:** https://emersonrc26.github.io/checklist-campo/

- Android (Chrome): abra o link e toque em "Instalar".
- iPhone (Safari): Compartilhar → "Adicionar à Tela de Início".

Depois de instalado, funciona sem internet. Relatórios e fotos ficam só no celular de quem preenche, criptografados.
